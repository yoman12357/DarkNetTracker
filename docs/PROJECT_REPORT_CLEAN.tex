\begin{abstract}
This report documents the DARK (Distributed Anonymous Routing Correlation Kit) project - a full-stack traffic correlation platform for cybersecurity research. The project implements a complete analysis system with Python backend engine, Express.js REST API, SQLite persistence, and Next.js dashboard frontend. All 86 identified issues have been resolved, comprehensive security hardening implemented, and production-ready deployment configured. Current status: \textbf{READY FOR PRODUCTION}.
\end{abstract}

\chapter{Architecture}

\section{System Architecture}

The project uses a three-tier architecture:

\begin{lstlisting}[language=bash]
Frontend Layer (React/Next.js) :3000
   Dashboard | User Management | Monitoring
        |
   REST API + WebSocket
        |
Backend Layer (Express.js) :4000
   Auth | Job Queue | Report Generation
        |                  |
   SQLite Database    Python Analysis Engine
   Users|Sessions|    Simulate|Replay|PCAP|Live
   Jobs|Audit
\end{lstlisting}

\subsection{Component Interactions}

Request Flow:
\begin{enumerate}
    \item Frontend sends request to Backend API
    \item Backend validates input and checks permissions
    \item Backend creates Job and queues it
    \item Job Queue spawns Python subprocess
    \item Python Engine processes data
    \item Backend stores results in database
    \item WebSocket broadcasts update to frontend
    \item Frontend displays results
\end{enumerate}

\section{Data Flow}

Analysis Pipeline:

\begin{lstlisting}
Raw Events -> Extract Features -> Correlate Hops -> 
Rank Paths -> Estimate Regions -> Evaluate -> Report
\end{lstlisting}

\section{Database Schema}

Primary Tables:
\begin{itemize}
    \item \textbf{users}: id, username, password\_hash, role, created\_at
    \item \textbf{auth\_tokens}: token, user\_id, expires\_at, revoked\_at
    \item \textbf{sessions}: id, mode, status, config, result, timestamps
    \item \textbf{jobs}: id, session\_id, status, attempt\_count
    \item \textbf{audit\_logs}: id, actor\_id, action, target\_type, metadata
\end{itemize}

Indexes on: user\_id, created\_at DESC, status, lease\_expires\_at

const upload = multer({

  fileFilter: (_req, file, cb) => {
    const allowed = [
      'application/octet-stream',
      'text/plain', 'text/csv', 'application/json'
    ];
    if (allowed.includes(file.mimetype)) {
